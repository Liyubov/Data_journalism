# Data journalism course
Course on data journalism and new resources.

# Course objectives 
The main objectives of the course are:
1. to be able to create stories from data 
2. to discover Data Journalism Workflows
3. to create and work on the project related to the topic of the 

We are generally interested to teach students to understand general important structure in Data Journalism as a field separate from data science or simple journalism. 
We will work on the storytelling, data journalism and examples of complex data visualisation, will go from 2D to Data representation use cases of visualisation and will speak about the advanced data analysis attuned to the data science projects which students are currently having.

# Main resources 
We will work with various resources such as 
1. Data journalism handbook https://www.researchgate.net/publication/281376035_The_Data_Journalism_Handbook
2. Data for journalism materials from various media resources such as the Guardian, Le monde
3. Documentalistic cinema materials. 



Main repository is located here https://github.com/Liyubov/Data_journalism/, yet some data-analysis related resources are located in the repository with projects here https://github.com/Big-data-course-CRI/
